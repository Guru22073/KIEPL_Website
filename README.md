# KIEPL Website

[![Website Status](https://img.shields.io/badge/status-active-success.svg)](https://github.com/Guru22073/KIEPL_Website)
[![GitHub License](https://img.shields.io/github/license/Guru22073/KIEPL_Website)](https://github.com/Guru22073/KIEPL_Website/blob/main/LICENSE)

A responsive, modern website for Kamaleswar India Engineering Private Limited (KIEPL), an Indian company specializing in mechanical and engineering infrastructure services, focusing on development and installation of machinery, industrial projects, and plant maintenance in the steel and aluminum sectors.

## ✨ Features

- **Responsive Design**: Fully optimized for all device sizes
- **Dynamic Navigation**: Interactive dropdown menus with smooth animations
- **Video Background**: Engaging hero section with background video
- **Animated Content**: Smooth entrance animations for enhanced user experience
- **Interactive Carousel**: Showcase company projects and work examples
- **Search Functionality**: Full-text search across the website
- **Mobile-Friendly Sidebar**: Collapsible sidebar menu for mobile devices
- **Scroll Reveal Effects**: Content reveals as users scroll down the page
- **Modern Footer**: Multi-column footer with social media links and contact information


## 🛠️ Technology Stack

- **Frontend**:
  - HTML5
  - CSS3
  - JavaScript
  - jQuery 3.6.0
  - ScrollReveal.js
  - IonIcons

## 💻 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Guru22073/KIEPL_Website.git
   cd KIEPL_Website
   ```

2. **Setup local development server**:
   You can use any local server solution such as:
   - Live Server extension for VSCode
   - Node.js http-server:
     ```bash
     # If you have Node.js installed
     npx http-server
     ```

3. **Open in browser**:
   Navigate to `http://localhost:8000` or the port your server is running on.

## 🚀 Usage

The website is designed to be intuitive and easy to navigate:

- **Navigation**: Use the top menu or the sidebar (on mobile) to navigate between pages
- **Search**: Use the search box to find specific content across the site
- **Carousel**: Click on the indicators or arrow buttons to navigate through the image carousel
- **About Section**: Read about the company and its key statistics
- **Team Section**: Learn about the company leadership
- **Footer**: Access quick links and contact information
